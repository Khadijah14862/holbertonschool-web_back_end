# Python - Async Comprehension

## Description
This project explores asynchronous programming in Python using
asynchronous generators and asynchronous comprehensions.

## Learning Objectives
- Understand how asynchronous generators work.
- Learn how to use `async` and `await`.
- Use `async for` to iterate over asynchronous generators.
- Write asynchronous comprehensions.
- Apply type annotations to asynchronous generators.

## Requirements
- Python 3.8
- Ubuntu 20.04 LTS
- PEP 8 coding style
- All Python files must include documentation and type annotations.

## Tasks

### 0. Async Generator
File: `0-async_generator.py`

Creates an asynchronous generator that:
- Loops 10 times.
- Waits 1 second during each iteration.
- Generates a random float between 0 and 10.
- Uses `yield` to return values one at a time.

## Usage

Run the test file:

```bash
python3 0-main.py
```
